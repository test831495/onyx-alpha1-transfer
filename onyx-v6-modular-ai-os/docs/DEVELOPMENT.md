# Development

## Commands
- `pnpm dev`: run the React command center.
- `pnpm build`: build all workspaces.
- `pnpm typecheck`: strict TypeScript validation.
- `netlify dev`: run frontend plus functions after Netlify configuration.

## Definition of done
- Contract tests pass.
- No secret appears in the frontend bundle.
- NOVA and ONYX microphone ownership is mutually exclusive.
- Plugin scope review passes.
- Keyboard, touch and voice paths have been tested.
- v5.14 compatibility decision is documented.
