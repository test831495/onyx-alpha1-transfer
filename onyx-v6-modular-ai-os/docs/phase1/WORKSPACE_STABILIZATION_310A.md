# Alpha 3.1.0a Workspace Stabilization

- Contains long Microsoft profile names and email addresses inside provider cards.
- Adds natural profile aliases such as `Who I am`, `Show my profile`, and `My account`.
- Treats unavailable mail, calendar, OneDrive, and SharePoint features as informational `COMING SOON` states rather than errors.
- Preserves Microsoft authentication, session restoration, Workspace layout, and Alpha 3.0.2 runtime behavior.
