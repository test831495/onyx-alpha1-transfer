# NOVA Local Intelligence

## Phase 1 Objectives

NOVA should provide:

- File Search
- Document Search
- Photo Search
- Video Search
- Music Search
- Calendar Search
- Weather
- News
- App Launching

---

## Restricted Actions

NOVA must not perform:

- Purchases
- Financial Transactions
- File Deletion
- Security Changes
- Unlocking Doors
- Alarm Disarming

without additional verification.

---

## Core Principle

Local-first intelligence.

Cloud intelligence remains optional.
