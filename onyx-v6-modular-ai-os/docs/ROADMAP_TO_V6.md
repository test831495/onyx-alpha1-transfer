# Roadmap to v6

## Phase 0: Baseline freeze
- Preserve v5.14 source and deployment artifact.
- Capture regression tests and design tokens.

## Phase 1: Modular shell, v5.20
- React dashboard, stateful AI core, dual NOVA/ONYX modes.
- Shared contracts, privacy router, event bus and mock modules.

## Phase 2: Local intelligence, v5.30
- File System Access API adapter, document parsers, screenshot capture, IndexedDB memory, system diagnostics.
- Desktop companion evaluation for capabilities unavailable to browsers.

## Phase 3: Cloud intelligence, v5.40
- Server-side ElevenLabs tokens, finance/news adapters, Microsoft Graph OAuth, Home Assistant connector.

## Phase 4: Automation and plugins, v5.50
- Workflow designer, schedules, approval queue, signed plugin registry, execution history.

## Phase 5: Security and reliability, v5.90
- Authentication, per-user vault, audit trail, rate limiting, encrypted memory, observability, backups and disaster recovery.

## Phase 6: Production v6.0
- Stable plugin API, migrated workflows, accessibility certification, cross-device QA, performance budget, production rollout and rollback plan.
